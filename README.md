# Hall Effect Sensors Project

## Project Specification

This project aims to deliver a laboratory-ready magnetic field mapping system based on a distributed array of Hall effect sensors. It comprises of a hardware and a software platform that is capable of measuring magnetic fields generated by a variety of Helmholtz coil configurations. The developed sensor array is integrated with an existing image-based diagnostic suite, enabling synchronised measurement using the MatchID digital image correlation (DIC) software and National Instruments (NI) data acquisition hardware. 

### Objectives
* design and construct an array of Hall effect sensors for magnetic field strength measurements
* develop an Arduino-based data acquisition system for sensor interrogation and data collection
* develop Python software for data acquisition, logging, processing, visualisation and analysis
* design and manufacture sensor support structures using CAD software and in-house 3D printing facilities
* integrate the sensor array with the MatchID data acquisition and image-based diagnostics platform
* develop calibration methodologies and assess measurement uncertainties
* generate magnetic field maps for multiple Helmholtz coil configurations
* produce complete technical documentation, operating procedures, and user guidance

### Deliverables
* A validated Hall effect sensor array for magnetic field measurements
* Arduino firmware repository and associated documentation
* Python software package for data acquisition and analysis
* CAD models and STL files for all manufactured components
* sensor calibration procedures and uncertainty assessment documentation
* magnetic field mapping datasets for multiple Helmholtz coil configurations

# Hall Effect Sensor Project

This repository contains all the information about the hall effect sensor array. The first stage of the project is starting with a basic version of the project. I will start with a few hall effect sensors and construct a working circuit with working software. The end goal of this project is to create a magnetic field map using hall effect sensors and integrate that into MatchID software to get a live feed of the magnetic field strength distributions across a sample undergoing deformation.
